# SASM - Simple Assembler Suite

Depends on [YAPL](https://github.com/AnonymousDapper/yapl) for parsing

Very much a prototype currently, but look at the [LC3 plugin readme](https://github.com/AnonymousDapper/sasm/blob/main/sasm/plugins/lc3/README.md) and [test.py](https://github.com/AnonymousDapper/sasm/blob/main/test.py) for an idea of how this works.
